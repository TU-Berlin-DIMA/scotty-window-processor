# Spark Connector

Uses Scotty as a window operator in [Apache Spark](https://spark.apache.org/) Structured Streaming.
`KeyedScottyWindowOperator` is a `FlatMapFunction` that is applied to a `Dataset` of `DemoEvent`s.

The [Spark demo](../demo/spark-demo) shows how to use it.
The [demo README](../demo/README.md#running-the-demos) describes how to run it.
